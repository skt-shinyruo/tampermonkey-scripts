# ADR 0004: 市场页容器宽度倍率缩放与自适应满宽机制

A6API 官方市场页（`#/market`）将主内容区域硬编码约束在狭窄的固定最大宽度（约 1200px），在现代宽屏显示器上导致两侧存在大量未利用空间，同时使 11 列模型数据表格产生横向滚动与截断换行。

我们决定在 Tampermonkey 脚本中引入市场容器宽度缩放机制：
1. 默认提供预设档位（原版 1.0x、1.35、1.55、100% 满宽自适应）、实时拖拽滑块以及直接输入自定义数字倍率；
2. 动态改写市场主容器的 `max-width` 与 `width`，使顶部多维筛选区与数据表格一体化横向舒展；
3. 严格限制仅在 `#/market` 路由生效，并在离开市场页时自动释放原版样式。

这彻底消除了数据表格截断与横向滚动条，显著提升了宽屏显示下的数据浏览吞吐效率。
