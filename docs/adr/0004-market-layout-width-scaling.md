# ADR 0004: 市场页容器宽度倍率缩放与自适应满宽机制

A6API 官方市场页（`#/market`）将主内容区域硬编码约束在狭窄的固定最大宽度（约 1200px），在现代宽屏显示器上导致两侧存在大量未利用空间，同时使 11 列模型数据表格产生横向滚动与截断换行。

我们决定在 Tampermonkey 脚本中引入市场容器宽度缩放与信息密度增强机制：
1. 默认提供预设档位（原版 1.0x、1.35、1.55、100% 满宽自适应）、实时拖拽滑块以及直接输入自定义数字倍率；
2. 容器以视口可用宽度为硬上限（`min(calc(100vw - 32px), ...)`），仅对官方内容主体根容器放宽 `max-width`，不污染子组件 `max-w-` 样式，并添加横向溢出保护，彻底根治底部横向滚动条；
3. 宽屏下激活「筛选平铺流」，品牌与模型标签解除单行截断，自动多行平铺展示更多选项；
4. 实施「紧凑指标排版」，固定数值指标列宽度，将伸展空间全量让渡给商家/模型文本与展开详情，同时收拢行内边距提升纵向吞吐密度；
5. 严格限制仅在 `#/market` 路由生效，并在离开市场页时自动释放原版样式。
这彻底消除了数据表格截断与横向滚动条，显著提升了宽屏显示下的数据浏览吞吐效率。
