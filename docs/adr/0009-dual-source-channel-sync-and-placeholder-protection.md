# ADR 0009: 双源渠道信息同步与脱敏占位符保护

此前在 ADR 0007 中，快捷渠道在市场页（`#/market`）统一通过公开检索接口（`/api/marketplace/public/channels/search?channel_id={cid}`）同步名称与状态。由于上游对公开市场检索实施了匿名化脱敏，统一返回 `Channel ID {id}` 等占位符，且对无公开在售模型的渠道返回空结果，导致用户的「我的渠道」真实名称被批量污染为 ID，并因公开市场无模型被大面积误判为「已下架」。

我们决定将渠道信息同步分流为双源架构：
1. **我的渠道（Owned Channel）**：以商户中心接口（`/api/supplier/me/channels`）与渠道管理页 DOM 为唯一权威源，严格获取商户真实名称与在架状态，严禁使用公开市场接口覆盖「我的渠道」，解耦公开供给与在架状态；
2. **自定义渠道（Custom Channel）**：继续通过公开市场检索接口同步，但建立脱敏占位符保护规则（匹配 `/^(?:Channel|Supplier)\s*(?:ID|#)?\s*\d+$/i`）。若返回占位符且本地已有名称，禁止覆盖；仅在无本地名称时允许作为回退展示；
3. **自愈与状态反馈**：抽屉工具栏的同步操作主动请求商户中心接口修复已被污染的历史脏数据，并在未登录商户或同步成功时向用户提供明确的交互状态提示。
