# ADR 0010: 渠道自定义资产备份与覆盖合并恢复

用户的自定义渠道（`a6_custom_channels`）与渠道备注（`a6_channel_remarks`）属于单机本地持久化的核心资产。当用户卸载重装插件、清除浏览器缓存或更换设备/浏览器时，缺乏可导出的持久化载体，将导致用户长期维护的渠道别名、业务备注以及界面排版偏好全部丢失。

我们决定在 A6API 脚本中建立标准化的数据备份与恢复体系：
1. **导出结构与版本控制**：支持将自定义渠道、渠道备注、用户偏好配置（市场宽度、抽屉方位、自动翻页）以及商户自有渠道快照打包导出为带版本签名（`version: 1`）和时间戳的标准 JSON 文件；
2. **导入覆盖合并策略**：导入时采用「覆盖合并（Merge & Overwrite）」算法，对于相同渠道 ID，以导入文件中的名称、说明与备注为准覆盖，同时保留本地既有未冲突的新增项，防止误伤；
3. **双重交互入口**：在快捷渠道抽屉工具栏提供「💾 备份/恢复」直观操作入口，并在 Tampermonkey 扩展菜单注册对应全局命令，保障极端情况下依然能导出与恢复数据。
