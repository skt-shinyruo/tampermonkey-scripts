# ADR 0003: 市场模型列表自选渠道高亮规则与互斥机制

在市场页（`#/market`）浏览海量模型与供货商时，商户需要快速辨识哪些模型由自己的「快捷渠道」（商户自有渠道与自定义渠道）供货。

我们决定在未指定渠道搜索时（包括无输入浏览、按品牌/模型筛选、或按「模型」/「描述」维度搜索），自动提取市场行内的「渠道 #ID」并高亮显示命中的快捷渠道行。而在用户切换到「渠道」维度并输入特定渠道 ID 检索时，自动抑制（关闭）高亮。

在视觉与结构呈现上：
1. **首尾单元格内嵌描边（Inset Border）**：避免直接给 `tr` 添加外扩投影被表格容器的 `overflow: hidden` 裁切左右边框；首列 `td:first-child` 补充左内嵌与左圆角，尾列 `td:last-child` 补充右内嵌与右圆角，右侧操作按钮区预留内边距并融入底色，杜绝悬浮截断；
2. **一体化闭合包裹大卡片（Unified Card Enclosure）**：当模型行展开详情时，主行仅保留上、左、右边框（去底边），下属展开行（`.ant-table-expanded-row`）接续保留下、左、右边框（去顶边），两行共享浅金微光背景，中缝以淡虚线平滑衔接，视觉上闭合为一个完整的大卡片包裹住所有展开详情。

这种条件高亮机制避免了在单渠道搜索结果页全量高亮带来的视觉冗余，同时在跨渠道多选浏览与详情展开时最大化凸显自选渠道。
