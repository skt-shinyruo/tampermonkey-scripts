# ADR 0007: 快捷渠道公共接口异步同步与下架状态标识

此前在 ADR 0001 中，快捷渠道完全依赖用户手动访问渠道管理页（`#/merchant/channels`）通过 DOM 扫描沉淀数据，导致市场页中的渠道名称、说明和离线状态无法实时感知更新，且自定义渠道一旦录入即静态固化。

我们决定在市场页（`#/market`）引入基于官方公开检索接口（`/api/marketplace/public/channels/search?channel_id={cid}`）的异步数据同步体系，包含抽屉工具栏的主动批量同步（3 并发限流）与卡片点击时的被动同步（2 小时 TTL 节流）。当接口或管理页 DOM 确定渠道无供给或离线时，不再直接删除本地卡片，而是标记 `delisted: true` 并渲染明确的「已下架」状态徽章与半透明弱化样式，同时严格保护用户自定义的渠道备注（ADR 0002）不被覆盖。
