# ADR 0005: 快捷渠道检索与多维筛选重置联动

在市场页（`#/market`）中，用户常在多维快速筛选区针对特定品牌（如 OpenAI）或特定模型系列（如 gpt-6-luna）进行过滤。当用户在快捷渠道抽屉中点击任一快捷渠道（如 `#5973`）时，若保留前置狭窄筛选，极易因该渠道未供货当前筛选模型而展示「未找到符合条件的渠道」的虚假无货假象。

我们决定在点击快捷渠道检索时，自动靶向对齐重置上方的多维快速筛选至初始推荐状态：
1. **靶向标签对齐**：自动检查并点击未激活的「全部品牌」、「全部」(模型系列) 与「综合推荐 (默认)」标签；
2. **防竞态与无损输入**：避免调用官方破坏性的全量「重置所有筛选」按钮（该按钮会强制清空输入框并重置搜索维度至「模型」），防止与渠道 ID 的输入与检索产生前后网络请求竞态；
3. **反选行为保持现场**：在对已激活渠道卡片执行反选（Deselect）时，仅清空渠道 ID，保留商户当前的筛选微调现场。

这一联动机制确保了单渠道检索时始终展现该渠道下的完整模型货源，彻底消除了空结果假象。
